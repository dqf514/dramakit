# 写戏：一集怎么写

剧本管戏，分镜管拍——「爽不爽」和「怎么拍」是两种迭代节奏。所以这一层只有集、场次、节拍流，
没有镜号。镜头是下一层的事。

## 一、时长预算先于一切

**目标秒数就是墙**：台词按 4.5 字/秒、动作按 2.5 秒/拍折算。

- 三分钟一集约 45–55 拍。
- **写超了先砍动作节拍**，再压台词。
- **写欠了补冲突，不补寒暄**。

一集只有一场戏是广播剧；三句台词之间没有一个画面动作，就该问自己这场戏观众在看什么。

## 二、单句台词 ≤ 35 字，一口气说得完

长句拆成两句，中间可以插一拍动作或对方的反应。

## 三、谁的话像谁

船夫不说文言，小姐不说市井话。角色的性情、身份、说话方式在角色表里——写之前先读，**写的时候盖着名字也认得出是谁在说话**。

## 四、动作节拍一拍一件事，叙述体，动作要「常见」

「胡二爷的手停在半空，笑僵在脸上」是一拍；「气氛很尴尬」不是画面，写不得。**动作里不许出现引号台词。**

**常见动作是 AI 生成的生命线**——这条戏最终是视频模型演的，它只会演它见过千万次的动作：

| 写法 | 例子 | 生成结果 |
| --- | --- | --- |
| ✗ 精确物理交互 | 货担撞上船帮，铜铃碎响。老周伸篙一挡，担子稳稳落进舱里 | 篙、担、船帮三物交互，必崩 |
| ✓ 常见动作 | 胡二爷挑着担子上船，老周搭手帮他把担子卸进舱里 | 挑担、搭手、放下，全是常见动作 |

**判据：这个动作在生活视频里常见吗？** 上船、坐下、递东西、点头、回头、抱紧、站起来——放心写；
用工具挡住某物、微表情（睫毛颤）、以寸计的位移（收了半寸）、比喻性画面（像被雾攥住的茧）——改写或删。

**戏剧信息靠常见动作的组合与时机给，不靠动作本身的精巧。**

## 五、钩子不是标签，是第一拍，而且要在运动中给

每集第 1 拍冷开场：钩子的具象必须带主体运动。

- ✗ 静物特写一闪（旧皮箱抱在怀里，指节掐白）
- ✓ 抱着旧皮箱在雾里跑

奔跑、追赶、挣脱、猛地按住，都行；静态细节特写留给第二落点兑现。

**上一集的结尾悬念要在开场接住**——接住不等于立刻解开。

## 六、结尾最后一拍必须是悬念

一句没说完的话、一个没解释的动作、一声来历不明的响。戏里落成具体的一拍，不是旁白说一句「下集更精彩」。

## 七、改剧本的纪律（错误最常从单点修改混进来）

- **改一拍，连读三拍。** 任何节拍改动后，把前后各一拍连起来重读一遍，专查三样：**人物位置**
  （上一拍还在岸路，下一拍不能已经在栈桥上）、**道具在手状态**、**谁在场**。写作时空间状态在你
  脑子里，改的时候它不在——连读是把状态找回来的唯一办法。
- **改画面，带声景。** 剧本动作一改，下游分镜的描述和声景要一起动。

## 手感规则（不设门，但决定戏好不好看）

- **台词短，动作密。** 短剧的对话节奏比电视剧快一倍——两三句就要有一次动作或反应插进来，超过四句连续对白就闷了。
- **潜台词写进表演提示**，别把潜台词直接写成台词说破。
- **心声省着用。** 是强调不是拐杖，一集两三条封顶；用在「表面平静、心里翻江倒海」的错位时刻最值。
- **场次切换是免费的，注意力不是。** AI 换景不要钱，但观众每换一次景要重新建立空间感。两分钟内换四个景，还不如在一个景里把戏拧紧。

## 常见病

| 病 | 症状 | 治法 |
| --- | --- | --- |
| 广播剧 | 整场只有台词 | 每两三句台词之间插一拍画面动作 |
| 文学病 | 动作写成美文：伸篙一挡、睫毛颤 | 换成常见动作 |
| 开场死画面 | 第一拍是静物特写 | 同一具象换成运动中给，静帧挪到第二次出现 |
| 空间跳变 | 上一拍在岸路跑，下一拍写栈桥才露出来 | 改一拍连读三拍；位置是连续状态，跳变必须有走过去的拍 |
| 注水 | 寒暄、让茶、问路占了半集 | 删。每一拍要么推进剧情要么翻转关系 |
| 演讲癖 | 一个人连说四句 | 拆给对手，或用动作打断 |
| 全知病 | 台词把信息说尽 | 信息藏进动作，台词只说三分 |
| 断头戏 | 结尾平收 | 最后一拍换成悬念，哪怕只是一声汽笛 |
