# 迭代记录：10 轮短剧全链路测试

每一轮都是：**换一个新剧本 → 跑完整流水线 → 自动质检 → 找出问题 → 改代码 → 下一轮**。

## 目录

| 路径 | 内容 |
|---|---|
| `scripts/roundNN.txt` | 该轮的剧本（1 分钟以内的短小剧本，每轮一个题材） |
| `logs/roundNN.log` | 该轮流水线的完整日志 |
| `reports/roundNN.qa.json` | 该轮的质检报告（机器可读） |
| `../projects/轮次NN_*` | 该轮的**全部素材**：角色三视图、场景参考图、每镜首帧、每段视频、配音、字幕、成片、FCPXML |

跑一轮：

```bash
venv\Scripts\python.exe round.py --round 3
```

看所有轮次的对比：

```bash
venv\Scripts\python.exe rounds\summary.py
```

## 质检查什么（`qa.py`）

- **画面**：从成片抽 8 帧，测拉普拉斯方差（糊不糊）、亮度/饱和度的镜头间差异（调色有没有生效）
- **配音**：每句是否有音频、时长是否合理、同一情绪的句子时长是否雷同（平读就是雷同）
- **混音**：成片响度与真峰、对白与音乐的响度差（音乐会不会盖住对白）、黑帧
- **字幕**：条数对不对、一条几行、会不会超出画面宽度
- **FCPXML**：画面片段数和音轨（对白轨 + 音乐轨）齐不齐

## 10 轮各打什么

| 轮 | 题材 | 主要检验 |
|---|---|---|
| 1 | 便利店夜班 | 基线：全链路 + 质检基准 |
| 2 | 认亲宴 | 台词情绪 / 配音表现 |
| 3 | 停电三十七秒 | 夜景与调色一致性 |
| 4 | 年夜饭 | 多人对话 / 音色区分度 |
| 5 | 宫门外的雪 | 古风文言 / 字幕长度 |
| 6 | 转正通知 | 长台词 / 语速 |
| 7 | 请假条 | 快节奏短句 / 镜头数 |
| 8 | 第四个失踪者 | 暗场 / 黑帧 / 低对比 |
| 9 | 退婚 | 情绪爆发 / 配音张力 |
| 10 | 最后一单 | 回归：汇总所有改进 |
