# RTX 3090 双卡服务说明（Strata / ComfyUI）

> 适用机器：`192.168.31.8`（121GB RAM / **RTX 3090 ×2 24GB**）
> 更新日期：2026-11-03

## 现在的分工：一张卡一个服务，不用再切

原来是**一张卡两个服务分时用**——Strata 加载后显存几乎占满，ComfyUI 就没显存了，
所以每次用哪个都得先把另一个停掉。

现在机器上**有两张卡**，各干各的，谁也不用让谁：

| 卡 | 服务 | 显存占用 | 内存占用 | 端口 |
|---|---|---:|---:|---|
| **卡 0** | ComfyUI（出图 / 出视频 MiniMax-H3） | ~16.5 GB | ~48 GB | 8188 |
| **卡 1** | Strata（Qwen3.8-Flash-Next IQ3_XXS） | ~23.5 GB | ~45 GB | 8080 |

两边的显存互不相干，**不用再切了**。

## 卡 1：Strata（本地大模型，端口 8080）

引擎装在 `/root` 下（只有 root 读得到），所以它跑在一个容器里：
容器内的身份就是 root，机器的 `/root` 和模型数据挂进去，网络是主机的网络，
显卡也是主机的显卡——然后用 `--gpu 1` 告诉它**只用卡 1**。

```bash
# 启动（脚本在 E:\dramakit\rounds\tools\start_strata_gpu1.sh，远端副本 /opt/deploy/start-strata.sh）
bash /opt/deploy/start-strata.sh

# 容器已经设了 --restart unless-stopped：机器重启或引擎崩了，它自己回来
docker ps --filter name=strata-engine
```

验证：

```bash
curl -s http://127.0.0.1:8080/health
# {"status": "ok", "max_context": 131072, "model": "qwen3.8-flash-next-iq3_xxs", "images": true, "loaded": true, ...}
```

停止：

```bash
docker rm -f strata-engine
```

> **为什么用容器起**：引擎在 `/root/.local/bin/strata`，而 `david` 账号在 sudo 组里
> 但 sudo 要密码。容器内就是 root，于是不需要密码也能把引擎拉起来。
> 引擎是容器的子进程，容器没了引擎也就没了——所以容器必须留着。

| | |

**再开第三个吃内存的东西之前先看一眼 `free -g`。** 之前机器被拖死过一次：
两个 ComfyUI 实例各 45 GB，加起来 96 GB 常驻 + 每个进程还按「整台机器都是自己的」
去申请钉住内存（Linux 上单进程上限 109 GB），内核只能杀进程——表现就是
「TCP 秒连、HTTP 全超时、SSH 连 banner 都不回」。

ComfyUI 那边的教训已经记在 `E:\dramakit\rounds\星际骷髅兵-第一章-运行报告.md` 里，
并且已经修好：权重改成按需从 NVMe 读（`--fast-disk`）、关掉钉住内存、
共享内存从 8 GB 降到 2 GB。

## 状态速查

```bash
# 谁在占哪张卡
nvidia-smi --query-gpu=index,memory.used,memory.total --format=csv,noheader

# 两个服务各自的运行状态
curl -s http://127.0.0.1:8080/health        # Strata
curl -s http://127.0.0.1:8188/system_stats  # ComfyUI

# 内存
free -g
```

显存判读参考：

- **卡 0 ~16.5 GB**：ComfyUI 在跑（已载入模型）
- **卡 1 ~23.5 GB**：Strata 已加载模型
- **卡 1 接近 0**：Strata 没起

## 常见问题

**1. Strata 起不来，说显存不足**
卡 1 被别的东西占了。`nvidia-smi` 看卡 1 是谁在用。

**2. 机器很卡 / SSH 连不上**
内存吃完了。先 `free -g`，再 `docker stats --no-stream` 看谁在吃。
把 Strata 的上下文调小（`--context 64k`）能省几 GB 内存。

**3. 换了 IP 之后客户端连不上**
本机 IP 是 `192.168.31.8`（原来 31.7 已改）。
Strata 的地址是 `http://192.168.31.8:8080`，ComfyUI 是 `http://192.168.31.8:8188`。

**4. 忘了服务是哪个**
`nvidia-smi` 看占用：Strata 在卡 1（23.5 GB），ComfyUI 在卡 0（16.5 GB）。
