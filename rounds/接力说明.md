# 接力说明：下一次开机做什么

> 2026-10-29 状态。这一轮把"声音飘在画面外"和"画面扭曲"两件事查到了根，
> 修了，并且发现了一条更大的路：**让 H3 自己说话**。

## 一、这一轮的结论（都已验证）

| 问题 | 根因 | 现在的做法 |
|---|---|---|
| 画面扭曲 | `_fit_refs` 里 `iw` 未定义 → 竖版角色照污染出图 → 竖版视频被裁成横幅 | 已修；出图 768×1344、成片 1080×1920 |
| 声音和画面对不上 | 时间线把台词从它自己的镜头"抢走"塞给别的镜头，整场错位一格 | 分镜的分配是最终决定；长度上限只安置无家可归的台词 |
| 说话人不在画面里 | H3 提示词没说这一镜谁开口 | 提示词点名说话人，其余人闭着嘴只是听 |
| 台词被拉伸 | 句尾的留白算进了台词本身 | 台词保持录音的长度；留白是镜头末尾的空 |
| 各阶段时间线不一致 | `promptgen` 建的时间线没算留白 | 全流水线走 `ctx.timeline(ep)` |
| 画面里出现黄色文字 | 场景描述里带着引号里的台词，模型把它画成了字幕 | 画面描述里去掉引号内容；旁白只出声不显示 |
| 桌子在木纹和大理石之间跳 | 场景描述写的是 "warm wood **and** dark marble table" | 场景描述只许写一种；提示词说参考图是唯一标准 |
| **人声是乱码** | 一直在用 **fl2va**（首尾帧）模型，它不会说话 | 换 **ref2va**（参考图）模型，它能说中文 |

## 二、最重要的发现：`ref2va` 能说话

MiniMax H3 有两个开源 transformer：

- `fl2va`（首/末帧 → 视频+音频）：**人声出来是乱码**。我们以前只能把它的音频丢掉、
  用单独录的音做画外音——这就是"声音飘在画面外"的由来。
- `ref2va`（参考图/视频/音频 → 视频+音频）：**人声是清楚的中文**。

实测（whisper-small 转写）：

```
ref2va + <d>[zh-CN]我想清楚了。</d>   ->  「我想清楚了」   ✓
fl2va  + <d>[zh-CN]我想清楚了。</d>   ->  乱码
```

而且 ref2va 能吃**参考音频**：把我们的配音录音当 `<Audio 1>` 喂进去，
H3 就用那个音色说我们的话（官方原话："Audio carries timbre, not words"）。
所以现在是：**画面 + 嘴型 + 人声 + 音效一次出**，嘴和声音是同一次生成的。
